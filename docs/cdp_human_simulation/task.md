# CDP Human Mouse Simulation

## 目的
- CDP (Chrome DevTools Protocol) を使用した、人間らしいマウス移動と入力のシミュレーション実装。
- JSによるフォールバック実装を排除し、Bot検知回避能力を向上させる。
- マウス移動、クリック、入力における人間らしい挙動（揺らぎ、ミス、速度変化）を100% Rust/CDP側で再現する。

## 実装項目
- [x] Click Action (CDP) の `human_mode` 対応
  - ベジエ曲線による自然なマウス軌道
  - イーズイン・アウトによる速度変化
  - マイクロジッター（微細な手の震え）
  - オーバーシュート（行き過ぎて戻る動作）
  - 可変クリック遅延
- [x] Type Action (CDP) の `human_mode` 対応
  - 隣接キーの打ち間違い (Typo) シミュレーション
  - シフトキー操作ミス（大文字/小文字ミス）
  - 文字種別による入力速度の可変（句読点後の思考ポーズなど）
  - 高速入力コンボ（th, heなどの頻出パターン）
- [x] JS実装の廃止
  - `robustness.rs` 内の重複JSコードの削除
- [x] アーキテクチャ統合
  - MCPツール定義へのフラグ追加
  - Core/WebViewインスタンスへのパラメータ伝搬

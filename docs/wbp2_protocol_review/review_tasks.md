## 背景

PROTOCOL_V2.mdは複数のセッションで機能を追加しながら作成されたため、以下の問題が発生している：

1. **矛盾**: 前半と後半で異なる仕様が記載されている
2. **重複**: 同じ概念が複数箇所で異なる表現で説明されている
3. **未反映**: 後から決定した設計原則が前半部分に反映されていない
4. **用語不統一**: 同じものに異なる名前が使用されている
